## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| frozen document → three tracks | Everyone codes against the text; an ambiguous rule is resolved differently by each author. |
| engine stdout → console parser | Untrusted line stream; `info string` payloads can impersonate structure. |
| operator/engine → Rule 9 log | The log is the graded artefact; a missing field is a disqualification, not a bug. |

| T-01-08 | Repudiation | Contract re-opened after implementation starts | high | mitigate | Freeze commit touches only the two docs; `check_contract_order.py` proves ancestry against `src/`, `console/`, `pipeline/`; change control requires a dated revision (Task 3). |
| T-01-09 | Tampering | Mock silently diverging from the document it claims to prove | high | mitigate | Mocks are driven by the document's literals; `test_contract.py` asserts document ↔ mock ↔ CSV agreement in both directions (Task 3). |
