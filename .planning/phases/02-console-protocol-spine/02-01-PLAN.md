<objective>
**User story:** *As the console, I want one disciplined UCI channel to the engine — framed, whitelisted, id-tagged — so that exactly one search's `bestmove` can ever reach the operator and nothing else on the wire can move game state.*

Plan 02-01 of 3 (Phase 2 — Console Protocol Spine). Phase goal: a complete game through the console against stock Stockfish with every half-move logged and no illegal move ever reaching the board replica. This plan proves the wire format on the real binary, then builds the ~250-line transport every later layer runs on.

Purpose: the engine is a hostile peer — it exits on an illegal `position` (rc=1), floods stdout, and UCI has no request ids. Get the pipe discipline, the whitelist, and the stale-bestmove machinery right first, on the agent's best early context.
Output: `console/src/console/transport/` (uci.py, parser.py), a smoke entrypoint, transport tests, an extended contract test, and a committed wire-spike transcript.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine stdout → transport parser | Untrusted line stream; a corrupt/hostile engine line must not drive console state. |
| engine stderr → console | Crash/bench text must never interleave with the UCI stream. |
| operator/config → engine argv | Engine path and args become a subprocess invocation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | Engine stdout line interpreted as structure | high | mitigate | Whitelist parser (`parse_line`): only §5.1 tokens + bestmove/id/option/uciok/readyok produce typed events; everything else is inert garbage events; `--garbage` test proves no state effect (Task 2). |
| T-02-02 | DoS | TextIO+select starvation or silent engine wedges the console | medium | mitigate | `bufsize=0` raw-fd reads into an owned buffer (mock_gui pattern); per-read timeout surfaces `{"type": "timeout"}`; `--silent-hang` test asserts TimeoutError (Task 2). |
| T-02-03 | Tampering | stderr interleaved into the UCI parse stream | medium | mitigate | Dedicated stderr drain daemon thread, never merged (console delta vs mock_gui, Task 1); stderr-isolation stub test (Task 2). |
| T-02-04 | Tampering | setoption racing a live search (deadlock/crash hazard) | high | mitigate | Option queue flushable only when `outstanding is None`, after isready/readyok; `--crash-on-option` + transcript assertion prove the mid-search path never sends (Task 2). |
