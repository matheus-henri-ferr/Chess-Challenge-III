<objective>
**User story:** *As the operator, I want a keyboard console that accepts only legal moves, announces exactly what `bestmove` says, and survives wrong input and stale engine answers — so that no illegal move ever reaches the board replica and the prompt never dies under me.*

Plan 02-02 of 3 (Phase 2 — Console Protocol Spine). Purpose: this is the critical path — nothing later (clock, match, TM integration) attaches to anything but this spine.
